# 看材料

> 这个文件只解决一个问题：
>
> **题目到底给了我什么，我应该从材料里抓住什么？**
>
> 先读准，再解释。不要在读准之前猜原因、上价值、谈社会意义。

---

## 一、第一步：材料本身显示了什么

拿到材料，先做事实清单，不要急着分析。

### 图画

先看：

- 有谁 / 有什么对象；
- 他们在做什么；
- 在哪里；
- 有什么道具；
- 什么表情、姿态；
- 有没有标题、文字、对话；
- 是单图还是双图。

### 图表 / 表格

先看：

- 标题；
- 单位；
- 时间范围；
- 对象 / 类别；
- 每一行、每一列是什么；
- 数字大概在说什么。

### 文字材料

先看：

- 谁在说；
- 说了什么；
- 是陈述、评论、提问，还是对立观点；
- 有没有转折、让步、反问；
- 题目要求我做什么。

### 把“事实”和“解释”分开

例如：

- **事实：** 一个人坐在石阶上，另一个人递给他一瓶水。
- **解释：** 他想放弃；他没有毅力；他需要休息。

再如：

- **事实：** 空调拥有量从 75.2 台升到 145.9 台，洗衣机和冰箱基本在 100 台左右。
- **解释：** 消费升级；生活质量提高；家电普及。

事实是材料给的；解释是我加的。**先把事实读准，再决定解释到什么程度。**

> 一句话测试：我能不能用一句话说出“材料里发生了什么”？
>
> 如果说不出来，先不要写。

---

## 二、信息优先级

材料里通常有很多信息，但不是每个都值得写。优先级是：

```text
结构
> 对比
> 关系变化
> 代表性数字
> 次要细节
```

### 1. 结构

整体在发生什么？

- 总体趋势；
- 整体构成；
- 分组格局；
- 主要变化方向；
- 最突出的整体特征。

### 2. 对比

最大、最特殊、最值得比较的差异是什么？

- 最高 vs 最低；
- 多数 vs 少数；
- 一组 vs 另一组；
- 预期 vs 实际。

### 3. 关系变化

两者之间的关系有没有改变？

- 差距扩大 / 缩小；
- 排序变化；
- 趋同 / 分化；
- 交叉 / 赶超；
- 转折 / 拐点。

### 4. 代表性数字

哪 2–3 个数字最能证明上面的判断？

优先：

- 起点 + 终点；
- 最高 + 最低；
- 最关键的组间比较；
- 转折点 / 交叉点。

### 5. 次要细节

零散数字、装饰性细节、对主线没有帮助的信息，通常不写。

### 最重要的一条

> **逐项报数字不是观察，只是抄表。**

观察是：我从材料里看出了什么结构。
抄表是：我把表格里的数字按顺序念了一遍。

## 三、图表读取

### A. 先确认单位

先分清这些词：

| 说法 | 实际含义 |
|---|---|
| number | 数量 |
| percentage | 百分比 |
| share | 占比 / 份额 |
| growth rate | 增长率 |
| per capita | 人均 |
| per 100 households | 每百户 |
| percentage point | 百分点 |

为什么重要：

- 把“百分比”当“数量”，会误判规模；
- 把“百分点”当“百分比”，会误判变化幅度；
- 把“每百户”当“总数”，会误判普及程度；
- 把“增长率”当“绝对规模”，会误判谁更大。

> **硬纪律：先读单位，再读数字。**

### B. 先找整体结构

先判断这是什么类型的图表：

- 时间变化；
- 横向比较；
- 构成比例；
- 分组比较；
- 多维混合。

然后找最值得写的结构：

- 总趋势；
- 最大差异；
- 排名变化；
- 趋同 / 分化；
- 结构变化；
- 转折点；
- 异常点。

不要一上来就找一个“好写”的数字。先问：

> **这张图最想让人看到的结构是什么？**

### C. 必要时重建表格关系

柱状图、折线图会把结构画出来；表格不会。表格要自己重建：

```text
标题 → 单位 → 行是什么 → 列是什么
→ 是跨时间比，还是跨组比？
→ 整体结构 → 关键对比
```

先确认：

- 每一行代表什么；
- 每一列代表什么；
- 比较对象是谁；
- 比较维度是什么；
- 这些数字之间到底能不能直接比较。

如果行、列含义不清楚：

> **先别写。先弄清楚。**

### D. 压缩数字

默认目标：

> **1 个整体 pattern + 1 个关键 contrast + 2–3 个代表性数字。**

数字的选择标准不是“哪个最好写”，而是：

> **哪个最能证明我判断出的结构。**

常见压缩方式：

- 15 个数字，作文只写 3–4 个；
- 不逐年、逐项罗列；
- 用“总体 + 例外”代替“一个一个说”；
- 用“差距扩大 / 缩小”代替两组数字各念一遍；
- 用“结构变化”代替三个孤立变化。

一个简单训练：

> 10 个数据 → 压缩成 3 句。

如果 3 句还说不清，通常不是数字不够，而是结构还没找到。

## 四、图画材料

### 先看什么

- 人物 / 对象；
- 动作；
- 场景 / 道具；
- 表情 / 姿态；
- 对比；
- 象征元素；
- 标题 / 文字提示。

### 事实 vs 解释

图画题最容易犯的错，是把“解释”当成“事实”。

- **事实：** 两个人站在路口，一个向左，一个向右。
- **解释：** 他们意见不合；他们在做人生选择；他们互不理解。

- **事实：** 一个人低头看手机，桌上的人都在看他。
- **解释：** 他沉迷手机；他不尊重别人；他被科技异化。

事实可以写；解释要谨慎。**图中人物的心理、动机、品格，通常不是材料直接给出的。**

### 单图

先找最能说明主题的 **1–2 个细节**，不要试图把画面所有元素都写进去。

问自己：

- 哪个动作 / 对象 / 对比最能承载主题？
- 哪些细节只是背景？
- 标题有没有提示？

### 双图

先判断两幅图是什么关系：

- 对比；
- 变化；
- 同一方向；
- 平行；
- 中性并列。

> **双图不自动等于对比。**

如果两幅图其实在说同一件事的不同方面，不要硬写“形成鲜明对比”。

### 标题 / 文字

标题是材料的一部分，但不要过度解读每一个字。

先看：

- 标题在提示什么；
- 文字和画面是什么关系；
- 有没有反讽、双关、提问。

如果标题只是点题，不要把它强行解释成深层象征。

## 五、图画 + 图表组合材料

一画一表时，不要机械假设“图表就是在证明图画”。

先判断两份材料各提供了什么，常见有五类关系：

### 1. 具体画面 + 数据证据

画面给出一个具体场景，数据给出支持这个场景的证据。

### 2. 个体场景 + 宏观趋势

画面是一个人的经历，数据是更大范围的社会趋势。

### 3. 象征表达 + 数量证据

画面用象征方式表达一个意思，数据用数量说明它有多普遍 / 多严重。

### 4. 现象 + 规模

画面说明“这是什么现象”，数据说明“它有多大 / 有多普遍”。

### 5. 同一主题的两种平行表现

画面和数据不是谁证明谁，而是同一主题的两种表现。

### 判断顺序

```text
两份材料各提供了什么？
↓
是互相证明、互相补充，还是平行？
↓
再决定怎么把它们连起来
```

如果关系判断错了，后面写得再顺也会偏。

> **不要先决定“图表证明图画”，再去找证据。先看它们实际是什么关系。**

## 六、文字材料

文字材料也要先读准。

### 先分清

- 材料在陈述一个事实；
- 材料在表达一个观点；
- 材料在提出一个问题；
- 材料在呈现两种对立看法；
- 材料在给一个情境，让我评论。

### 注意

- 不要把“材料提到的观点”当成“作者支持的观点”；
- 不要把“材料里的一个例子”当成“普遍结论”；
- 注意转折、让步、反问；
- 注意题目要求：是让我描述、解释、评论，还是提建议。

### 一句话测试

> 这段材料到底在说什么？它要我干什么？

如果这两个问题答不清，先不要写。

---

## 七、Evidence Ceiling：解释不能超过材料

这是本文件最重要的边界。

> **解释的力度，不能超过材料真正支持的程度。**

### 同步变化 ≠ 因果关系

如果图表只显示：

> A 上升，同时 B 上升

那么最多可以写：

- 二者同时发生；
- 二者可能存在联系；
- A 可能对 B 有推动作用。

不能自动写：

> A 导致了 B。

### 没有证据时，不要虚构

不要虚构：

- 因果关系；
- 机制；
- 统计支持；
- 社会背景；
- 人物心理；
- 未来趋势。

可以提出合理解释，但要用与证据强度匹配的措辞。

### 三个强度层级

| 材料能支持到什么程度 | 我可以写到什么程度 |
|---|---|
| 材料直接显示 | 直接描述 |
| 材料支持一个简单解释 | 说“可能”“也许”“与……一致” |
| 材料没有提供支持 | 不写，或者明确标成“推测” |

### 一个简单测试

写完一句解释，问自己：

> **这句话，材料真的支持吗？**
>
> 如果材料只给了“同时发生”，我有没有写成“因为”？

## 八、读完材料，我应该带走什么

读完材料，至少要能回答下面五个问题：

1. **材料里发生了什么？**（一句话）
2. **最值得写的结构 / 对比 / 变化是什么？**（一句话）
3. **哪 2–3 个数字或细节能证明它？**
4. **我能解释到哪一步？**（描述 / 简单解释 / 完整分析）
5. **哪些是事实，哪些是我的解释？**

如果 1–3 答不出来：

> **回去再读一遍，不要急着写。**

如果 4 答不出来：

> **说明你还没决定这篇文章要写多深。**

如果 5 答不出来：

> **说明事实和解释已经混在一起了。**

## 九、常见错误

1. 按表格顺序逐项报数字。
2. 还没读准就开始猜原因。
3. 把百分比当数量。
4. 把百分点当百分比。
5. 把“每百户”当总数。
6. 把增长率当绝对规模。
7. 看到双图就写“形成鲜明对比”。
8. 看到一画一表就说“图表证明了图画”。
9. 把图中人物的心理、动机当成事实。
10. 解释超过材料支持的程度。
11. 材料还没读完，就开始想“高级意义”。
12. 把“材料简单”误认为“必须想深”。
13. 为了写满字数，把次要细节全部塞进去。
14. 只写数字，不写数字说明的结构。
15. 只写结构，不给任何证据。
