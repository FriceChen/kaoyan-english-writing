# 深层母题

> 这个文件不是题型分类，也不是万能升华库。
>
> 它只解决两个问题：
>
> **为什么有些问题总是反复出现？**
>
> **为什么有些价值长期都成立？**
>
> 它是在一篇作文已经有基本思路之后，才可能用到的深层备用工具；不是每篇作文的终点。

---

## 最低记忆要求

使用这个文件，最低只需要记住四件事：

1. 有些问题之所以反复出现，是因为背后有长期不变的现实条件；
2. 有些冲突之所以反复出现，是因为两边都有真实价值；
3. 真需要时再查具体条目，不需要背完整清单；
4. 已经够写，就不要来这里。

> 不需要背“7 + 8 + 9 = 24 个概念”。
>
> 你只需要知道：**长期现实**和**长期张力**两类东西；具体条目是查的，不是背的。

---

## 一、什么时候需要看这里

适合：

- 已经有一个正常中心；
- 想解释某个价值为什么长期存在；
- 想解释某个矛盾为什么不是一次性问题；
- 一个问题在很多不同题材中反复出现；
- 两边都有真实价值，无法简单消灭一边；
- 需要给已有分析补一个更深但仍然相关的背景。

不适合：

- 材料还没看懂；
- 没有中心；
- 缺话题知识；
- 不会英语；
- 普通分析已经够写；
- 只是想“升华一下”；
- 想强行套哲学。

最重要的一句：

> **深层母题不是默认终点。大多数作文根本不需要走到这里。**

## 二、底层现实：为什么这些问题总会出现？

> 这一节回答：**什么样长期不变的条件，让某些问题反复有土壤？**
>
> 底层现实不是原因词，不是机制，不是价值本身，也不是写作结论。它只提供背景，不直接替你写中心判断。

### 现实一：资源有限

**现实是什么：** 人的时间、注意力、精力、金钱、认知容量都有限。
**它会制造什么长期问题：** 必须选择；选择意味着放弃别的选项；一个东西占用更多资源，另一个东西就得到更少；需要优先级、节制和效率。
**它通常让哪些价值变得重要：** 优先级、选择能力、节制、效率、合作（因为不能什么都自己来）。
**使用边界：** 典型题：工作与休闲、手机使用、学习计划、公共预算、消费分配。任何资源分配问题，先检查“有限性”；如果没有明确的有限资源，不要硬说“挤占”。

### 现实二：世界不确定

**现实是什么：** 人无法完全知道未来结果、成功概率、未来风险、长期后果。
**它会制造什么长期问题：** 必须在信息不完整时行动；必须承担判断错误的风险；需要准备，但不能等到完全确定。
**它通常让哪些价值变得重要：** 自信、勇气、谨慎、规划、风险管理。
**使用边界：** 典型题：自信、乐观、选择、创业、职业规划。很多“信念 / 勇气 / 谨慎”类价值，都源于“人在不确定中仍必须行动”；但不要让不确定性变成万能背景。

### 现实三：人的能力有限

**现实是什么：** 没有人能够知道一切、做一切、掌握所有领域，或独自解决所有复杂问题。
**它会制造什么长期问题：** 个体无法独自完成复杂任务；需要分工、合作、学习他人；需要工具和制度来扩展能力。
**它通常让哪些价值变得重要：** 合作、专业化、分工、向他人学习、工具使用。
**使用边界：** 典型题：团队合作、跨学科学习、合作、AI / 工具增强。“能力有限”不是“人很无能”；它只解释为什么合作、分工和工具长期有价值。

### 现实四：人彼此依赖

**现实是什么：** 人的行为往往不会只影响自己。
**它会制造什么长期问题：** 个人行为的成本和收益会跨越个体边界；一个人方便，可能让别人承担代价；需要信任、责任、公平和公共规则。
**它通常让哪些价值变得重要：** 责任、信任、合作、公共道德、公平、公共物品。
**使用边界：** 典型题：乱扔垃圾、养老、环境保护、公共行为、家庭责任。不要把一切公共问题都归咎于个人道德；也要看制度、设施和成本分配。

### 现实五：结果常常延迟出现

**现实是什么：** 很多行为是“现在付成本，以后才有收益”，或者“现在享受，以后付代价”。
**它会制造什么长期问题：** 人容易高估眼前、低估以后；需要坚持、耐心和长期规划；也容易拖延、成瘾、追求即时满足。
**它通常让哪些价值变得重要：** 坚持、耐心、习惯、长期规划、延迟满足。
**使用边界：** 典型题：坚持、锻炼、储蓄、学习、拖延、健康。不是所有“短期不舒服”都值得坚持；要看长期收益是否真实存在。

### 现实六：人和人不一样

**现实是什么：** 不同人、不同阶段、不同能力、不同目标、不同环境并不相同。
**它会制造什么长期问题：** “一刀切”很少成立；同一个方案对不同人效果不同；条件、阶段、边界变得重要；需要灵活判断。
**它通常让哪些价值变得重要：** 判断力、灵活性、因材施教、条件化思考。
**使用边界：** 典型题：教育、职业选择、社会规范、技术使用、健康行为。个体差异不是“每个人都只能顾自己”；它只说明统一方案需要条件。

### 现实七：环境一直在变

**现实是什么：** 技术、人口、经济、制度、文化环境持续变化。
**它会制造什么长期问题：** 旧能力可能失配；旧制度可能滞后；新需求会出现；适应变得重要。
**它通常让哪些价值变得重要：** 适应能力、终身学习、制度更新、开放心态。
**使用边界：** 典型题：AI、老龄化、城市化、传统文化、数字鸿沟、终身学习。“环境变化”不是“旧的东西一定没用”；它只说明匹配关系会变。

### 价值接口：解释价值时，可以优先看哪类现实

> 只用旧文件已有的典型对应，不把它扩成价值词典。

| 如果我在解释这种价值 | 可以优先看哪类底层现实 |
|---|---|
| 自信 / 勇气 / 谨慎 | 世界不确定 |
| 合作 / 分工 / 工具使用 | 人的能力有限 + 人彼此依赖 |
| 坚持 / 耐心 / 长期规划 | 结果常常延迟出现 |
| 责任 / 信任 / 公平 | 人彼此依赖 |
| 适应 / 终身学习 | 环境一直在变 |
| 判断力 / 灵活性 | 人和人不一样 |
| 优先级 / 节制 / 效率 | 资源有限 |

## 三、长期张力：为什么这些两难总会回来？

> 这一节回答：**为什么两种都真实的价值，会长期拉扯？**

一个真正的长期张力，通常满足五条：

1. 两边都有真实价值或功能；
2. 冲突来自长期存在的人类 / 社会条件；
3. 不能通过一次政策或一次选择永久消灭；
4. 会跨不同题材反复出现；
5. 能解释“为什么同类问题不断回来”。

它不是：

- 好 vs 坏；
- 一次性社会问题；
- 必须被彻底解决的 bug。

> 如果一边明显就是错误、低效、伤害，那通常不是张力，只是问题。
>
> 不要把明显坏的东西包装成“另一种价值”。
>
> 这些条目是知识结构，不是考试时必须依次运行的程序。具体话题只是这些长期张力在某一个时代、场景里的表现。

### 张力一：当下 ↔ 长期

**两边是什么：** 眼前的满足、效率、舒适 ↔ 未来的能力、健康、稳定、可持续。
**为什么冲突：** 底层来自“结果延迟出现”。常见表现：即时满足 ↔ 长期成就、舒适 ↔ 长期成长、休息 ↔ 坚持、消费 ↔ 储蓄、娱乐 ↔ 学习、拖延 ↔ 提前准备、短期成绩 ↔ 长期能力、快速答案 ↔ 深度学习、当前利益 ↔ 后代利益、眼前效率 ↔ 长期可持续。失衡：当下过强 → 拖延、成瘾、冲动消费、浅层学习；长期过强 → 倦怠、永久自我牺牲、无法享受当下。
**什么时候值得看：** 坚持、拖延、锻炼、AI 学习、环境保护、储蓄 / 消费、健康。
**最容易误用：** 不要写成“要平衡眼前和未来”就结束；也不要因为长期重要，就否认当下生活的价值。

### 张力二：保存 / 安全 ↔ 成长 / 适应

**两边是什么：** 保留已有价值、提供安全 ↔ 探索、改变、适应新环境。
**为什么冲突：** 人既需要守住已经有效的东西，又必须面对不断变化的环境。常见表现：保护 ↔ 锻炼、安全 ↔ 探索、稳定 ↔ 改革、传统 ↔ 创新、连续性 ↔ 变化、风险规避 ↔ 尝试、舒适区 ↔ 新挑战、保存经验 ↔ 学习新事物、制度稳定 ↔ 制度更新。失衡：保存过强 → 僵化、停滞、依赖、抗拒变化；适应过强 → 失去连续性、身份侵蚀、不稳定。
**什么时候值得看：** 温室花朵、育儿、传统文化、改革、终身学习、冒险。
**最容易误用：** 不要写成“传统 vs 现代，谁更好”；真正的问题是“什么该保留，什么该改变”。

### 张力三：便利 / 效率 ↔ 自主 / 能力

**两边是什么：** 省时省力、提高效率 ↔ 自主判断、能力形成、掌控感。
**为什么冲突：** 人希望降低成本，但能力形成往往依赖努力过程。常见表现：AI 辅助 ↔ 独立思考、自动化 ↔ 人类技能、导航 ↔ 空间判断、推荐算法 ↔ 自主选择、搜索答案 ↔ 自己推理、父母帮助 ↔ 孩子独立、高效率 ↔ 深度、外部记忆 ↔ 内部掌握、工具便利 ↔ 能力保持。失衡：便利过强 → 替代、依赖、能力侵蚀；自主过强 → 拒绝有用工具、不必要的低效。
**什么时候值得看：** AI、自动化、智能手机、教育技术、父母支持、数字工具。
**最容易误用：** 不要写成“技术一定有害”；关键判断是：工具承担的是低价值步骤，还是能力形成所需的核心过程。

### 张力四：自我 ↔ 相互依赖

**两边是什么：** 个人目标、利益、独立 ↔ 公共利益、合作、责任。
**为什么冲突：** 个体有自己的目标和利益，但生活在相互影响的社会中。常见表现：个人利益 ↔ 公共利益、独立 ↔ 合作、个人发展 ↔ 家庭责任、私人便利 ↔ 公共成本、个体选择 ↔ 社会后果、自我实现 ↔ 互助、竞争 ↔ 合作、私人消费 ↔ 环境成本。失衡：自我过强 → 外部性、搭便车、成本转嫁；相互依赖过强 → 过度从众、压制个体自主。
**什么时候值得看：** 合作、责任、环境保护、养老、公共道德、竞争。
**最容易误用：** 不要把所有集体要求都写成“高于个人”；也不要把所有个人选择都写成“自由”。

### 张力五：自由 / 选择 ↔ 规则 / 协调

**两边是什么：** 个人行动空间、选择自由 ↔ 共同规则、秩序、协调。
**为什么冲突：** 重点不是“我和别人利益冲突”，而是“个人行动空间如何与共同规则共存”。常见表现：言论自由 ↔ 他人免受伤害、市场自由 ↔ 监管、个体选择 ↔ 公共秩序、开放 ↔ 管理、灵活性 ↔ 标准化、创新自由 ↔ 安全规范、学术自由 ↔ 学术诚信、网络匿名 ↔ 问责、公共开放 ↔ 专业环境保护、AI 使用自由 ↔ 学术规范。失衡：自由过强 → 协调失败、共同条件受损；规则过强 → 僵化、压制自主、减少创新。
**什么时候值得看：** 言论、市场、公共秩序、开放与管理、创新与安全、学术规范。
**最容易误用：** 不要写成“规则越多越好”或“自由越大越好”；要问规则服务于什么共同条件。

### 张力六：个性 / 自主判断 ↔ 归属 / 社会连接

**两边是什么：** 做自己、独立判断、个人表达 ↔ 融入群体、归属、共同身份。
**为什么冲突：** 人既需要成为自己，也需要被群体接纳。这里用“归属”而不是“从众”，因为两边都是真实价值。常见表现：个人兴趣 ↔ 同伴评价、做自己 ↔ 融入群体、独居自由 ↔ 社会连接、个人表达 ↔ 群体规范、独特性 ↔ 共同身份、人口流动 ↔ 稳定关系、私人生活 ↔ 社区参与、亚文化 ↔ 主流文化、全球身份 ↔ 本土认同。失衡：个性过强 → 孤立、断连、拒绝一切共同规范；归属过强 → 从众、失去独立判断。
**什么时候值得看：** 同伴压力、爱好、社交媒体、传统文化、原子化、孤独、青年身份。
**最容易误用：** 不要把“归属”写成“从众”；也不要把“个性”写成“只顾自己”。

### 张力七：主观认知 ↔ 客观现实

**两边是什么：** 信念、感受、直觉、预期 ↔ 事实、证据、客观能力。
**为什么冲突：** 人需要信念和意义来行动，但现实会纠正错误的判断。常见表现：自信 ↔ 客观能力、乐观 ↔ 风险、主观感受 ↔ 客观事实、直觉 ↔ 数据、印象 ↔ 实际、舆论 ↔ 事实、自我认知 ↔ 外部反馈、预期 ↔ 实际结果。失衡：主观脱离现实 → 过度自信、偏见、错误信息、一厢情愿；只承认“客观现实”而否定主观作用 → 忽视动机、期待、意义、不确定下的信心。
**什么时候值得看：** 自信、乐观、社交媒体、舆论、错误信息、自我评价。
**最容易误用：** 不要写成“只要相信就能成功”；也不要写成“感受都是假的”。

### 张力八：指标 / 数量 / 表象 ↔ 实质 / 质量 / 目的

**两边是什么：** 可测量的数字、形式、外在表现 ↔ 真正想实现的质量、目的、实质。
**为什么冲突：** 真正目标往往难以直接测量，所以社会会使用替代指标。正常关系是“实质 → 指标”；失衡后变成“指标 → 目标”。常见表现：分数 ↔ 学习、学历 ↔ 能力、论文数量 ↔ 科研质量、KPI ↔ 实际绩效、粉丝数 ↔ 真实影响、买书 ↔ 读书、打卡 ↔ 真正完成、形式 ↔ 内容、外表成功 ↔ 真实成长、GDP ↔ 福祉。失衡：指标过强 → 脱钩、指标博弈、形式主义、替代指标优化；完全没有指标 → 难以评价、缺乏问责、协调困难。
**什么时候值得看：** 分数、KPI、论文数量、打卡、形式主义、排名、GDP。
**最容易误用：** 不要写成“所有测量都是坏事”；测量是必要的，问题是替代指标取代了目的。

## 四、常见派生两难（只作检索）

> 这些不是新的核心概念，而是核心张力在具体题目中的表现。不要把它们提升成另外 9 个一级模块。

| 常见两难 | 更接近哪个核心张力 | 什么时候常见 |
|---|---|---|
| 竞争 ↔ 合作 | 自我 ↔ 相互依赖；资源有限；能力有限 | 内卷、团队、市场竞争 |
| 繁荣 ↔ 可持续 | 当下 ↔ 长期；私人收益 ↔ 公共成本 | 环境、消费、发展 |
| 传统 ↔ 创新 | 保存 / 安全 ↔ 成长 / 适应 | 文化、非遗、改革 |
| 工作 ↔ 休闲 | 当下 ↔ 长期；资源分配 | 加班、工作生活平衡、健康 |
| 专精 ↔ 广度 | 效率 ↔ 适应性；深度 ↔ 整合 | 教育、职业、通识 |
| 开放 ↔ 身份 | 适应 / 交流 ↔ 连续 / 归属 | 全球化、移民、文化认同 |
| 效率 ↔ 公平 | 绩效优化 ↔ 相互依赖 / 分配 | 政策、教育、资源分配 |
| 隐私 ↔ 便利 | 自主 / 控制 ↔ 效率 / 个性化 | 数字服务、平台、监控 |
| 安全 ↔ 创新 | 保存 / 安全 ↔ 成长 / 实验 | 监管、技术、风险 |

## 五、常见组合（只作示例）

真实题目经常同时触及多个张力。下面只列最典型的几个，不是组合库。

| 题目类型 | 可能涉及的长期张力 | 提醒 |
|---|---|---|
| AI 教育 | 便利 / 效率 ↔ 自主 / 能力；当下 ↔ 长期 | 先判断工具承担的是低价值步骤还是核心练习 |
| 手机 / 线上社交 | 便利 / 连接 ↔ 自主 / 注意力；个性 ↔ 归属 | 不要写成“线上坏、线下好” |
| 内卷 | 自我 ↔ 相互依赖；当下竞争 ↔ 长期代价；指标 ↔ 实质 | 先找“为什么大家越努力越没用”的机制 |
| 传统文化 | 保存 ↔ 适应；个性 / 全球化 ↔ 归属 / 身份 | 关键是什么该保留、什么该改变 |
| 环境保护 | 当下 ↔ 长期；私人收益 ↔ 公共成本；繁荣 ↔ 可持续 | 不要把公共问题全部道德化为个人责任 |
| 养老 | 个体独立 ↔ 社会相互依赖；环境变化 ↔ 制度适应 | 形式可以变，责任不一定消失 |
| 过度保护 | 安全 ↔ 成长；便利 / 帮助 ↔ 能力 | 关键是帮助是否替代了能力形成过程 |
| 形式主义 | 指标 / 表象 ↔ 实质 / 目的 | 先问“本来想实现什么” |

## 六、怎么用，不怎么用

### 1. 不强制调用

不要拿到任何题都问“这是哪个长期张力”。如果题目已经很好写：

> 直接写。

### 2. 它不负责“解决”

长期张力的作用是：**解释为什么这种问题长期反复出现。**

很多张力本来就没有一次性 solution。可能的处理方式包括：给一边优先级、按场景区分、设边界、分阶段处理、重新定义两边关系、承认代价但仍然选择其中一边。

> **存在张力，不等于答案一定是“平衡二者”。**

### 3. 它不是“判关系”

“判关系”可以判断替代、互补、挤占、错配、条件关系。

长期张力回答的是：**为什么这种价值冲突会长期反复。**

不是所有 A/B 关系都是张力。

### 4. 它不是机制

张力解释“为什么冲突长期存在”；机制解释“冲突具体如何发生”。

例如：“便利 ↔ 能力”是张力；“工具替代练习 → 练习不足 → 能力退化”是机制。

### 5. 它不是“对立统一”

不要为了哲学感，把任何两个词都包装成“对立统一”。

“A vs B → 共同核心 C”是一种关系破题方法，不是长期张力本身。

### 6. 它不是必须被“解决”的 bug

有些问题只能管理、权衡、设边界、调整优先级，而不是永久消灭。

### 7. 它不是 thesis

底层现实和长期张力只能帮助你产生或深化判断。最终判断仍然必须回到具体题面：

- 这道题到底在问什么？
- 材料支持到什么程度？
- 我的中心判断是什么？

### 8. 成熟故事的接口

以后 `08_成熟故事.md` 里的成熟故事，通常是：

> **底层现实 + 长期张力 + 机制 + 一个稳定判断** 的组合。

本文件不提前迁移任何具体故事。

## 七、和其他工具的边界

| 工具 | 回答的问题 | 和本文件的区别 |
|---|---|---|
| `01_看材料` | 材料显示了什么？ | 先读事实，不要先哲学化 |
| `02_判关系` | A 与 B 是什么关系？ | 判关系处理替代 / 互补 / 错配等；张力处理“为什么长期反复” |
| `03_问价值` | X 为什么值得？ | 价值讲“为什么需要”；本文件讲“为什么这种需要长期有土壤” |
| `04_找失灵` | 本来应该实现什么，哪里断了？ | 失灵讲具体功能失败；张力讲长期冲突背景 |
| `05_机制` | 中间发生了什么？ | 机制是过程；张力是长期拉扯 |
| `06_换个角度看` | 是否漏掉一个维度？ | 换角度是方法；张力是内容 |
| `07_深层母题` | 为什么总回来？ | 只在需要解释“长期性”时使用 |

特别提醒：

- **底层现实 ≠ 机制**：“资源有限”是现实；“A 占用更多资源 → B 被挤压”才是机制。
- **换角度 ≠ 长期张力**：“短期和长期不同”只是时间角度；只有两边都有持续真实价值、反复冲突，才可能是张力。
- **判关系 ≠ 长期张力**：不是所有 A/B 关系都是张力。
- **张力 ≠ 机制**：张力解释为什么长期存在；机制解释具体如何发生。
- **张力 ≠ 对立统一**。
- **张力不是必须被解决的 bug**。
- **底层现实 / 张力都不是 thesis**。
- **材料没有明显呈现长期结构时，不要哲学化**：只有材料本身明显涉及短期 / 长期、效率 / 能力、指标 / 实质等，才考虑深层母题；否则先读数据。
- **失灵诊断仍然优先**：张力可以解释“为什么反复”，但不能替代 `04_找失灵` 的五步诊断。

## 八、最简流程

```text
我已经有正常中心了吗？
↓
有
↓
我是真的需要解释“为什么这个问题总回来”吗？
├─ 否 → 不用
└─ 是
     ↓
是长期现实在起作用，
还是两种真实价值在拉扯？
     ↓
查一个最相关的条目
     ↓
它有没有真正改变 / 加深我的判断？
├─ 否 → 丢掉
└─ 有 → 留下
     ↓
回到题面
     ↓
够写就停
```
