# 考研英语一大作文：闭卷运行卡

> 复杂体系用于训练；这张卡用于考场。

---

## 0. 真正要背的核心卡

```text
先看懂题。

我知道中心是什么吗？
我有 2 个能展开的点吗？
我知道为什么吗？
我知道英语怎么说吗？

都知道 → 直接写。
不知道 → 只补缺的那一洞。

Normal First：正常题直接写。
够写就停。
先找一个核心判断；一个核心能撑住，就不叠第二个。

深度：L0 描写 / L1 简单判断 / L2 一条完整分析 / L3 第二层限定或深化。
题目决定深度；L0 / L1 也可以是正确答案。

Thought Gap ≠ Content Gap ≠ Language Gap。
缺话题 → 素材；缺英语 → 表达；缺分析 → 思路。

材料支持到哪，就写到哪；相关 ≠ 因果。

四件事清楚 → 写：中心 + 两段 + 一条为什么 + 英语够。
```

---

## 1. 卡住了：先判断缺什么

| 我卡在哪 | 去哪 |
|---|---|
| 材料没看懂 | `01_看材料` |
| 看懂了，但不知道重点 | `01_看材料` |
| 缺话题知识 / 概念 / 例子 | `02_素材` |
| 知道内容，但组织不起来 | `01_思路` |
| 知道意思，但不会英语写 | `03_表达` |
| 其实够写，只是觉得“不够高级” | 直接写 |

不要用思路工具解决词汇问题，也不要用素材解决逻辑问题。

---

## 2. 材料没看懂

**图表：** 单位 → 总体结构 → 最明显关系 → 代表数字 → 一句话趋势。
默认压缩：**1 个模式 + 1 个对比 + 2–3 个代表数字**；不抄所有数字。

**图画：** 谁 → 在做什么 → 对比 / 异常 → 文字 / 标题 → 可能象征什么。
> 事实和解释分开：“低头看手机”是事实；“沉迷、孤独”是解释。

**图 + 表：** 先分别看懂，再判断二者是什么关系；不要默认“图表证明图画”。

---

## 3. 思路卡住：四个动作

> 不是四步流程，只是四个入口。

**看材料：** 发生了什么？最值得写的结构 / 对比 / 变化是什么？

**判关系：** 先问 A 和 B 是不是同一层；再看替代 / 互补 / 挤占 / 错配 / 条件关系；再问标准、边界、短期还是长期。
> 不写“二者都很重要”；不看到 A/B 就强行“辩证统一”。

**问价值：** 人的真实处境 → 没有 X 会失去什么 → X 为什么值得。不是罗列“很多好处”。

**找失灵：** 目的 → 本来应该怎么发挥作用 → 现在实际怎样 → 哪一环失灵 → 真正损失是什么。
> 再分：方向错 vs 方向对但不够 / 没转化成功。

---

## 4. 还不够：机制 / 角度 / 母题 / 故事

**机制：** 只记 `A → 中间环节 → B`。
需要时问：资源怎么分？谁替代谁？能力怎么形成 / 被削弱？哪里转化失败？指标是否偏离实质？成本转给谁？有没有反馈 / 放大？是否错配 / 不可及？

**角度：** 目的 / 时间 / 尺度 / 分配 / 边界 / 反事实 / 视角 / 基线。
> 当前思路缺维度时才换角度。Lens ≠ Mechanism：角度告诉你往哪看；机制告诉你那里发生了什么。

**深层母题：** 如果问“为什么总回来”，看是不是来自：资源有限 / 不确定 / 人有局限 / 彼此依赖 / 反馈延迟 / 个体差异 / 环境变化。
八个极简张力：现在↔未来、安全↔成长、便利↔能力、自己↔他人、自由↔规则、个体↔归属、认知↔现实、指标↔实质。
> 不是每题都要升华。

**常用故事：** 故事是查的，不是每题必须调用。
1 工具越强，人反而越不会；2 联系更多，关系未必更深；3 养老方式会变，责任不会消失；4 资源给了，学习仍要自己发生；5 选择越多，判断越稀缺；6 传统要活下来，形式必须改变；7 私人方便，公共买单；8 从“有没有”到“好不好”；9 生活更方便，健康不能外包；10 有，不等于用得上。

## 5. 熟悉领域：话题思路入口

> 熟悉领域但想法太泛时才查；不是必查。

```text
就业 → 教育 / 技能 / 就业链
健康 → 结果 / 行为 / 条件
AI → 任务 / 输出 / 真实 / 责任
数字 → 接入 / 信息 / 推荐 / 数据
环境 → 减缓 / 适应；单位 / 总量
文化 → 活态传承 / 权属
教育 → 理解 / 迁移 / 评价
社会 → 共同体 / 参与 / 信任 / 制度
```

---

## 6. STOP

只要已经有：中心判断 + 正文展开点 + 一条为什么 + 基本英语表达：

> **停止找理论，开始写。**

如果第二个机制 / 母题 / 故事不改变 thesis、不增加必要解释、不限定已有判断：

> **删掉。**

---

## 7. 写作前 10 秒

```text
中心是什么？
正文两段各干什么？
为什么成立？
材料真的支持吗？
够了吗？
```

够 → **写。**
