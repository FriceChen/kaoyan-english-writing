## 一、知道 ≠ 理解 ≠ 会做 ≠ 能迁移

**核心区分**

- **记住 ≠ 理解**：能背出信息，不等于能解释、联系和应用。
- **知道 ≠ 理解**：知道一个结论，不等于理解它为什么成立。
- **理解 ≠ 会做**：看懂，不等于能独立完成。
- **会做 ≠ 能迁移**：在熟悉题型里会做，不等于能在新情境中调用和重组。
- **能迁移 ≠ 能继续学**：真正稳定的能力还包括自主更新、继续学习。
- **理论要通过实践转成能力**：理论提供模型和原则，实践负责检验、应用和修正。

**本领域链：**

```text
知识 / 信息
→ 理解（能解释、联系）
→ 指导下的练习
→ 独立完成
→ 新情境迁移
→ 自主学习 / 继续更新
```

**为什么成立**

每一层都是不同的学习结果，不能互相替代。相关：`05_机制.md` 的能力形成 / 转化；`08_常用故事.md` 的“资源给了，学习仍要自己发生”（只链接，不复制）。

**常见题目**

阅读理解、课堂学习、考试备考、实践课程、AI 辅助学习、终身学习、学会学习。

## 二、教学 ≠ 学习

**核心区分**

- **教学 ≠ 单向输出**：教师讲完，不等于学生学会。
- **教学 ≠ 学习**：教师提供解释、任务、反馈；学生还要主动加工、练习、修正。
- **反馈 ≠ 只判对错**：有效反馈要说明“哪里错了、为什么错、怎么改”。
- **纪律 ≠ 放任，也 ≠ 过度控制**：清晰规则提供结构，但过度控制会压缩自主空间。
- **失败 ≠ 能力不足**：失败可以是反馈，帮助学生发现弱点、调整方法。
- **不同学生需要不同支持**：同一种教法不一定适合所有人。

**本领域链：**

```text
教师解释 / 任务 / 反馈
→ 学生主动加工
→ 练习
→ 反馈
→ 修正
→ 内化
```

**为什么成立**

教学是输入，学习是学生自己发生的过程；教师能创造条件，但不能替学生完成加工。相关：`05_机制.md` 的能力形成 / 反馈延迟；`08_常用故事.md` 的“资源给了，学习仍要自己发生”（只链接）。

**常见题目**

课堂教学、翻转课堂、辅导班、反馈与评价、学生参与、纪律与自主、因材施教。

## 三、分数 / 证书 ≠ 学习 / 能力

**核心区分**

- **考试 ≠ 学习目的**：考试能提供信息，但不应该成为学习的唯一目标。
- **分数 ≠ 完整能力**：分数测量某些方面，不能完整描述一个人的能力。
- **排名可能改变学习目标**：当排名成为主要关注，学生可能更在意超过别人，而不是提升自己。
- **证书 ≠ 学习 ≠ 技能 ≠ 能力**：学历/证书是教育成就的信号，不等于实际会做，更不等于能迁移。
- **评价应支持学习**：评价的功能是提供信息、改进学习，不是替代学习。

**本领域链：**

```text
测量
→ 激励
→ 学习行为适应指标
→ 分数提高
→ 真正理解 / 能力未必同步
```

**为什么成立**

评价工具测的是可测的部分，不是能力的全部；当指标变成目标，学习行为会围绕指标调整。相关：`05_机制.md` 的指标博弈 / 脱钩；`07_深层母题.md` 的指标 ↔ 实质；`01_职场与就业.md` 的“学历 ≠ 技能”（劳动市场侧，只链接）。

**常见题目**

应试教育、分数焦虑、排名、学历贬值、证书、学术评价、考试改革。

## 四、资源公平 ≠ 学习公平

**核心区分**

- **入学 ≠ 学习**：扩大入学率，不等于提供优质教育。
- **资源相同 ≠ 结果相同**：给每个人一样的东西，不等于公平；不同学生面临的障碍不同。
- **可及 ≠ 质量**：有学校、有设备、有课程，不等于有有效学习。
- **包容 ≠ 只是录取**：真正的包容还包括参与、被支持、能受益。
- **教育能促进流动，但不能独自消除不平等**：教育可以削弱部分起点差异，但不能解决所有社会不平等。

**本领域链：**

```text
家庭 / 经济背景
→ 教育可及性
→ 教育质量
→ 参与 / 支持
→ 学习结果
→ 机会差异
```

**为什么成立**

资源只是入口，学习还需要质量、支持、时间和转化条件；同样的资源对不同学生的实际价值不同。相关：`05_机制.md` 的可及性障碍 / 转化 / 错配；`07_深层母题.md` 的个体差异；`08_常用故事.md` 的“有，不等于用得上”（只链接）。

**常见题目**

教育公平、城乡教育、数字教育鸿沟、弱势学生、教育资源分配、教育政策、辅导班。

## 五、不同支持 ≠ 低一级 / 低标准

**核心区分**

- **一种教法 ≠ 适合所有学生**：学生能力、兴趣、背景、需求不同，需要灵活支持。
- **职业教育 ≠ 低一级教育**：职业教育提供实用的技能路径；学术路径不一定适合所有人。
- **不同路径 ≠ 降低要求**：提供不同支持，不等于放弃合理挑战；好教育既要有支持，也要有要求。
- **多元路径 ≠ 分层淘汰**：分流应该提供机会，而不是提前判定谁不行。

**本领域链：**

```text
学生差异
→ 不同支持 / 不同路径
→ 参与
→ 学习
→ 发展
```

**为什么成立**

教育要匹配学习者的条件和需求；匹配不等于降低标准，而是让不同人有机会达到合理要求。相关：`07_深层母题.md` 的个体差异；`01_职场与就业.md` 的职业教育 / 就业结果（只链接）。

**常见题目**

因材施教、职业教育、普职分流、个性化学习、特殊教育、学术 vs 职业路径。
