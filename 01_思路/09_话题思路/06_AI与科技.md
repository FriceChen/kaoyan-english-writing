## 一、AI 改变的是任务，不是整个职业

**核心区分**

- **任务 ≠ 职业 ≠ 人的角色**：AI 可能替代某些任务、增强另一些任务、创造新任务；这不等于整个职业消失。
- **自动化 ≠ 失业**：自动化先改变任务构成，再改变技能需求，最后才可能影响岗位数量。
- **辅助 ≠ 替代**：同样是 AI，可能承担低价值重复步骤，也可能绕过核心判断过程；关键看它替代了什么。
- **技术变化 ≠ 只能阻止**：更现实的问题是 adaptation：哪些任务消失、哪些新任务出现、人能不能移动过去。

**本领域链：**

```text
AI 能力
→ 任务自动化 / 增强
→ 任务构成变化
→ 技能需求变化
→ 再培训 / 适应
→ 职业变化
```

**为什么成立**

职业不是单一任务，而是一组任务的组合。AI 往往先进入“可分解、可重复、可验证”的任务，再改变整个职业的内容。相关：`05_机制.md` 的替代 / 互补 / 滞后；`02_判关系.md` 的替代 / 互补 / 条件关系。

> 就业卷已经从劳动市场角度使用“AI 暴露 ≠ AI 替代”；这里只保留技术层的“任务—职业—角色”结构，不重复就业后果。

**常见题目**

AI 取代工作、未来职业、自动化、人机协作、再培训、技能需求变化。

## 二、有输出 ≠ 有理解 / 有能力

**核心区分**

- **有输出 ≠ 有理解**：得到一个答案，不等于理解它为什么成立。
- **更快的答案 ≠ 更深的学习**：AI 降低获取答案的成本，但理解仍需要主动加工、练习和迁移。
- **辅助 ≠ 替代**：AI 可以帮助思考，也可以把思考过程整个外包。
- **会用 AI ≠ 会写 prompt**：AI 素养还包括知道系统能做什么、什么时候该怀疑它的输出。
- **过度依赖 → 判断力外包**：当用户习惯把判断交给 AI，便利可能以独立推理为代价。

**本领域链：**

```text
AI 输出
→ 更快得到答案
→ 减少主动加工
→ 理解 / 判断 / 迁移能力可能变弱

另一条：AI 辅助
→ 提供反馈 / 降低阻力
→ 主动参与 + 批判评估
→ 学习增强
```

**为什么成立**

理解不是“看到答案”，而是能解释、能验证、能在新情境中重建。相关：`05_机制.md` 的能力形成 / 侵蚀；`08_常用故事.md` 的“工具越强，人反而越不会”（只链接，不复制故事正文）。

**常见题目**

AI 教育、AI 写作、学生使用 AI、批判性思维、学术诚信、AI 辅助学习。

## 三、能生成 ≠ 真实 / 可靠

**核心区分**

- **AI 输出 ≠ 可靠证据**：生成流畅、看起来合理，不等于真实或可靠。
- **流畅 ≠ 真实**：语言自然、结构完整，只能说明“像”，不能说明“对”。
- **生成成本下降 → 验证成本相对上升**：内容越多，筛选、核验和判断来源越重要。
- **技术能力 ≠ 社会可欲性**：能生成某种内容，不等于应该生成、传播或使用它。

**本领域链：**

```text
生成成本下降
→ 内容数量增加
→ 验证负担上升
→ 来源核验 / 判断力变得更重要
```

**为什么成立**

生成式系统擅长产生“看起来合理”的内容，但真实性需要证据、来源和验证。相关：`01_看材料.md` 的 Evidence Ceiling；`07_深层母题.md` 的主观认知 ↔ 客观现实。

**常见题目**

AI 虚假信息、deepfake、AI 生成内容、信任危机、事实核查、AI 版权与原创性。

## 四、能做决定 ≠ 应该独立做决定

**核心区分**

- **技术能力 ≠ 合法权限**：AI 能做出某个决定，不等于它应该独立做这个决定。
- **预测 ≠ 责任**：AI 可以提供预测或建议，但责任不能随预测一起外包。
- **算法一致 ≠ 公平**：同样的规则重复执行，也可能复制数据里的偏见。
- **AI 建议 ≠ 最终权威**：AI 可以辅助判断，但高风险决定需要 human oversight。
- **技术方案 ≠ 社会方案**：技术能解决部分执行问题，不能自动解决价值、权利和分配问题。
- **治理 ≠ 阻止创新**：好的治理是让创新可信，不是让创新消失。
- **目标由人决定**：AI 可以帮助决定“怎么达到”，但“要不要追求这个目标”仍应由人判断。

**本领域链：**

```text
AI 能力
→ 预测 / 推荐
→ 决策支持
→ 风险：不透明 / 偏见 / 监督不足
→ 不公平结果 / 信任下降
→ 人类监督 + 透明 + 问责
```

**为什么成立**

高风险决定影响人的机会、权利和安全，所以需要透明度、可申诉、责任归属和人类监督。相关：`05_机制.md` 的外部性 / 脱钩；`07_深层母题.md` 的自我 ↔ 相互依赖、指标 ↔ 实质。

**常见题目**

算法偏见、AI 招聘、自动驾驶、医疗 AI、AI 治理、监管、AI 责任归属、deepfake 监管。

## 五、AI 普及 ≠ 能力普及 / 收益共享

**核心区分**

- **采用 ≠ 生产率**：装了 AI 工具，不等于组织真的提高了生产率；还需要技能、流程和组织能力。
- **可及 ≠ 有效使用**：能接触 AI，不等于会用、用得起、用得对。
- **AI 素养 ≠ 会写 prompt**：还包括理解限制、评估输出、判断适用场景。
- **技术平等 ≠ 结果平等**：同样的工具，对不同资源、技能和位置的人效果不同。
- **创新 ≠ 新奇**：技术新颖不等于解决真实问题；价值取决于是否真的有用。
- **AI 收益 ≠ 自动共享**：生产率提高，不等于收益平均分配；这部分与就业卷交叉，只链接，不重复。

**本领域链：**

```text
AI 能力
→ 需要基础设施 / 数据 / 技能 / 资金
→ 采用能力不均
→ 生产率收益不均
→ 差距可能扩大

另一条：可及 + 培训 + 扩散
→ 更广泛的收益
```

**为什么成立**

AI 的收益不是“工具有了”就自动发生，而是经过采用、使用、组织整合和分配。相关：`05_机制.md` 的扩散 / 放大 / 转化；`07_深层母题.md` 的便利 ↔ 能力；就业卷的“AI 收益可能分配不均”。

**常见题目**

AI 鸿沟、中小企业采用 AI、发展中国家 AI、AI 与不平等、AI 生产率、AI 普及政策。

## 六、怎么用这一卷

1. 先判断题目是不是 **AI / 科技本身**：
   - 就业后果 → 先看 `01_职场与就业.md` 的“AI 暴露 ≠ AI 替代”；
   - 数字生活 / 社交媒体 / 隐私 → 不属于本卷；
   - 一般“工具与能力” → 先看 `08_常用故事.md` 的“工具越强，人反而越不会”。
2. 在本卷里选**一个**最相关的区分，不要五个板块全跑。
3. 链条只写到本题真正断的那一环。
4. 回到材料：材料支持“任务变化”，还是只支持“工具有了”？支持“输出不可靠”，还是只支持“有人担心”？
5. 够写就停。
