## 一、保存 / 记录 ≠ 活态传承

**核心区分**

- **记录 ≠ 传承**：档案、录音、影像能保存信息，不等于有人还在学、还在做。
- **保存资料 ≠ 活态实践**：没有学习者、实践者和社区，传统可能只剩“资料”。
- **数字化 ≠ 数字传承**：扫描、上传、建数据库解决“保存与接触”，不自动解决理解、实践和代际传递。
- **实体保存 ≠ 文化延续**：建筑保住了，原有社区和生活方式消失，可能只是“空壳式保护”。
- **传承 ≠ 复制**：下一代学习传统，不等于变成上一代的复制品。

**本领域链：**

```text
文化实践
→ 实践者
→ 学习者
→ 观察 / 练习
→ 习得技能
→ 持续参与
→ 新实践者
→ 下一代

断裂：没有学习者 → 实践者减少 → 社会场景消失 → 只剩档案记忆
```

**为什么成立**

有些知识存在于动作、判断和关系里，不能完全写成文字；没有学习者与实践者的连接，记录再完整也不等于“活着”。相关：`05_机制.md` 的转化 / 能力形成；`08_常用故事.md` 的“传统要活下来，形式必须改变”（只链接）。

**常见题目**

非遗保护、博物馆收藏、数字档案、古建筑保护、传统技艺、传承人、老城改造。

## 二、可见 / 消费 ≠ 理解 / 参与

**核心区分**

- **知道 ≠ 参与**：知道一个传统存在，不等于把它当成自己生活的一部分。
- **曝光 ≠ 理解**：看过短视频、展览、文创，不等于理解它的语境和意义。
- **可见 ≠ 有生命力**：被很多人看到，不等于还有人在实践、学习、传递。
- **流行 ≠ 文化价值**：市场热度不是文化价值的唯一尺度。
- **文化消费 ≠ 文化理解**：买文创、打卡博物馆、穿国潮，可能只是入口，不是终点。

**本领域链：**

```text
接触 / 曝光
→ 兴趣
→ 理解
→ 参与 / 实践
→ 认同
→ 传承
```

消费和传播可以打开入口，但不自动走到“理解”和“参与”。

**为什么成立**

可见性解决“被看到”，传承还需要“被理解、被实践、被传递”。相关：`05_机制.md` 的指标博弈 / 脱钩；`07_深层母题.md` 的指标 ↔ 实质。

**常见题目**

国潮、文创产品、博物馆热、非遗短视频、文化类综艺、文化旅游、 cultural tourism。

## 三、商业化 ≠ 必然破坏

**核心区分**

- **商业化本身不必与文化保护冲突**：市场收入可以让实践者靠传统技能生活，从而继续实践。
- **过度商业化可能让文化适应市场，而不是服务社区**：当市场需求比社区控制更强，意义可能被简化。
- **旅游可以创造保护资源，也可以制造保护压力**：游客带来收入，也可能挤压社区和生活方式。
- **收益是否回到文化持有者很关键**：如果收益不回到实践者，保护很难持续。
- **商业价值 ≠ 文化价值**：能卖钱，不等于文化意义还在。

**本领域链：**

```text
正向：市场需求 → 收入 → 可持续生计 → 更多实践者 → 传承
风险：市场主导 → 简化 / 去语境 → 社区控制下降 → 意义弱化
条件：社区 agency + 公平分配 + 可持续使用
```

**为什么成立**

商业化是条件判断，不是“好 / 坏”标签：它可能提供生存资源，也可能改变文化功能，关键看谁控制、收益归谁、意义是否还在。相关：`05_机制.md` 的指标博弈 / 脱钩；`07_深层母题.md` 的指标 ↔ 实质。

**常见题目**

文旅开发、非遗商业化、传统手工艺、节庆旅游、文创产业、古街商业化。

## 四、谁有权保护 / 定义

**核心区分**

- **列入名录 ≠ 得到保护**：官方认定能提高可见度，不等于实践还能继续。
- **外部保护 ≠ 社区传承**：专家和政府可以支持，但不能完全替社区决定传统怎么活。
- **自上而下的保护可能保住形式，却削弱主体**：形式被保护，实践者的能动性反而下降。
- **专家知识 + 实践者知识**：两者互补，不是谁替代谁。
- **政府支持 + 社区参与**：公共资源创造条件，传承最终靠人继续实践。
- **借用 ≠ 尊重性使用**：欣赏其他文化，不等于可以脱离来源、语境和社区随意使用。
- **可及 ≠ 无限制使用权**：公开可见，不等于没有所有权和同意问题。

**本领域链：**

```text
外部认定 / 资金
→ 保护条件改善
→ 但如果社区失去决定权
→ 形式被保留，实践主体被削弱
→ 文化生命下降
```

**为什么成立**

文化保护不只是“保住东西”，还涉及谁有权定义、使用、改编和获益。相关：`05_机制.md` 的外部性 / 成本转嫁；`07_深层母题.md` 的自由 ↔ 规则、自我 ↔ 相互依赖。

**常见题目**

非遗名录、 heritage listing、文化政策、博物馆策展、文化挪用、传统知识版权、社区参与。

## 五、交流 ≠ 同化；自信 ≠ 排外

**核心区分**

- **全球化 ≠ 必然同质化**：交流增加，不等于所有地方文化都会变成一样。
- **开放 ≠ 放弃身份**：接触其他文化，不必以放弃自身文化为代价。
- **交流 ≠ 单向模仿**：真正的交流是双向互动，不是一方复制另一方。
- **尊重 ≠ 无条件接受**：尊重文化差异，不等于放弃基本价值底线。
- **文化自信 ≠ 文化优越**：自信是知道自己是谁，不是排斥别人。

**本领域链：**

```text
流动 / 媒体
→ 接触
→ 比较
→ 交流
→ 新的创造形式

风险：文化生产权力不均 → 强势内容获得注意力 → 本地表达可见度下降 → 传承变弱
```

**为什么成立**

交流既可能丰富文化，也可能加剧不平衡；关键不是“开不开放”，而是本地文化有没有参与和交流的条件。相关：`07_深层母题.md` 的开放 ↔ 身份、个性 ↔ 归属。

**常见题目**

文化全球化、文化自信、外来节日、文化输出、跨文化交流、文化多样性、文化挪用。

## 六、怎么用这一卷

1. **传统要不要变 / 形式与内核 / authenticity**：直接用 `08_常用故事.md` 的“传统要活下来，形式必须改变”，不要在本卷重复。

3. **文化自信 / 全球化**：先看 `07_深层母题.md` 的开放 ↔ 身份；本卷只保留“交流 ≠ 同化”“自信 ≠ 排外”。
4. 在本卷里选**一个**板块，不要五个全跑。
5. 回到材料：材料支持“传承断了”“只是可见”“商业化改变了控制权”“谁有权定义”，还是“交流与身份”？只写材料支持的那一层。
