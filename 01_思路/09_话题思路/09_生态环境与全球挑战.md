## 一、减缓 ≠ 适应

**核心区分**

- **减缓 ≠ 适应**：减缓是减少未来气候变化，适应是降低已经发生 / 不可避免的影响。
- **未来减排 ≠ 当前风险立即消失**：即使排放下降，已经积累的气候风险仍然存在。
- **适应 ≠ 可以无限适应**：适应能降低损失，但不能无限抵消环境变化。
- **韧性 ≠ 永远不受冲击**：韧性是吸收冲击、维持功能、恢复和调整，不是“不会出事”。

**本领域链：**

```text
高排放活动
→ 排放
→ 气候变化
→ 物理影响
→ 社会 / 经济 / 生态损失

路径一：减缓 → 减少未来气候变化
路径二：适应 → 降低给定变化下的损失
```

**为什么成立**

两条路径解决的是问题的不同部分，不能互相替代：只减排不准备，会承受已发生风险；只适应不减排，问题会继续恶化。相关：`05_机制.md` 的滞后 / 阈值；`07_深层母题.md` 的当下 ↔ 长期。

**常见题目**

全球变暖、极端天气、碳中和、气候政策、城市韧性、灾害准备。

## 二、单位效率 ≠ 系统总压力

**核心区分**

- **单位效率 ≠ 总资源使用**：单件产品更节能，不等于总消耗下降。
- **效率 × 规模**：效率决定“每单位用多少”，规模决定“用了多少单位”；两者相乘才是总压力。
- **清洁能源转型 ≠ 只建新能源**：还需要效率、基础设施、系统灵活性。
- **可再生能源 ≠ 零环境影响**：低碳不等于无影响，要看全生命周期。
- **减少能源消费 ≠ 降低生活水平**：效率可以让同样的服务用更少能源。
- **技术更高效 ≠ 总环境影响必然下降**：成本下降可能带来更多使用。

**本领域链：**

```text
单位效率提高
→ 单位成本下降
→ 使用量可能增加
→ 总资源使用 / 总排放未必下降
```

**为什么成立**

环境压力看的是总量，不是单件指标。效率提高可能被规模扩大抵消。相关：`05_机制.md` 的放大 / 正反馈 / 边际递减；`07_深层母题.md` 的指标 ↔ 实质。

**常见题目**

绿色技术、电动车、新能源、节能产品、塑料替代、能源转型、循环经济。

## 三、污染治理 ≠ 污染预防；转移 ≠ 消除

**核心区分**

- **污染治理 ≠ 污染预防**：治理处理已经产生的污染，预防减少污染产生。
- **把污染移到别处 ≠ 解决污染**：从空气转到水、从本地转到外地、从本国转到别国，问题只是转移。
- **看不见污染 ≠ 没有环境成本**：供应链会把消费的收益和生产的污染分开。
- **生态恢复 ≠ 完全回到破坏前**：恢复功能不等于完全复原，防止不可逆损失更重要。
- **保护生物多样性 ≠ 只保护少数珍稀物种**：健康生态系统依赖物种之间的相互作用。

**本领域链：**

```text
需求 / 生产
→ 资源开采 / 能源使用
→ 排放 + 废物
→ 环境压力
→ 气候 / 生态 / 健康影响

干预点：减少不必要需求 / 提高效率 / 改变能源 / 延长产品寿命 / 预防污染 / 回收材料
```

**为什么成立**

越往下游，越只是处理后果；越往上游，越接近问题来源。相关：`05_机制.md` 的外部性 / 成本转嫁 / 转化；`08_常用故事.md` 的“私人方便，公共买单”（只链接）。

**常见题目**

空气 / 水 / 塑料污染、垃圾处理、供应链污染、生态修复、生物多样性、污染转移。

## 四、循环经济 ≠ 垃圾回收

**核心区分**

- **回收 ≠ 循环经济**：回收只是最后一环；循环还包括减量、耐用设计、重复使用、维修、再制造。
- **处理废物 ≠ 防止废物产生**：下游处理不等于上游预防。
- **绿色产品 ≠ 可持续消费**：买一个更环保的产品，不等于高消费生活方式已经可持续。
- **产品寿命长 ≠ 无法创新**：创新可以用于延长使用寿命，而不是加快替换。

**本领域链：**

```text
线性：take → make → waste

循环：reduce → durable design → use → reuse → repair
→ refurbish / remanufacture → recycle → less new extraction
```

**为什么成立**

循环的核心是“让材料和产品保留价值更久”，不是“废物产生后再回收”。相关：`05_机制.md` 的转化 / 上游干预；`07_深层母题.md` 的指标 ↔ 实质。

**常见题目**

垃圾分类、回收利用、塑料污染、快时尚、电子废物、循环经济、绿色消费。

## 五、个人行动 ≠ 系统变化

**核心区分**

- **环境意识 ≠ 环境行为**：知道环保重要，不等于能做到。
- **个人行动 ≠ 系统变化**：个人行为重要，但选择受价格、基础设施、产品可得性、监管、技术和社会规范约束。
- **绿色选项存在 ≠ 会被采用**：可及、可负担、方便，才可能变成行为。
- **基础设施会锁定长期行为**：一旦建成，交通和城市系统会把社会锁定在某种能源 / 资源使用模式里。
- **共同责任 ≠ 每个主体责任完全相同**：责任应反映“谁有能力塑造选择”。

**本领域链：**

```text
环境意识
→ 意愿
→ 可行选择（价格 / 基础设施 / 替代方案 / 监管）
→ 行为
→ 重复行为
→ 系统层面结果
```

**为什么成立**

个人选择发生在系统条件里；只呼吁个人，不改变条件，行为很难持续。相关：`05_机制.md` 的可及性障碍 / 挤占；`07_深层母题.md` 的自我 ↔ 相互依赖；`08_常用故事.md` 的“私人方便，公共买单”“有，不等于用得上”（只链接）。

**常见题目**

绿色生活、垃圾分类、限塑令、绿色出行、低碳生活、个人环保责任、公共设施。

## 六、怎么用这一卷

1. **绿色转型 / 就业 / 公平**：先看 `01_职场与就业.md`（岗位变化、再培训、分配）和 `07_深层母题.md`（当下 ↔ 长期、自我 ↔ 相互依赖）；本卷不重复。
2. **增长 vs 环保**：先看 `07_深层母题.md`；本卷只保留“效率 ≠ 总量”“治理 ≠ 预防”等环境专属结构。
3. **“保护环境很重要”**：如果题目只需要一般价值判断，直接写；不要为了用体系硬套五个板块。
4. 在本卷里选**一个**板块，不要五个全跑。
5. 回到材料：材料支持“排放 / 预防”“效率 / 总量”“回收 / 循环”“个人 / 系统”哪一层？只写材料支持的那一层。
