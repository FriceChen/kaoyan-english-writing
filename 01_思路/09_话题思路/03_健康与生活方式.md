## 一、健康结果 ≠ 健康行为 ≠ 行为条件

**核心区分**

- **健康 ≠ 没有疾病**：没有确诊疾病，不等于身体、心理、社会状态都良好。
- **健康结果 ≠ 健康行为**：看到肥胖、失眠、亚健康，不能直接推出“这个人不自律”。
- **健康行为 ≠ 行为条件**：行为发生在信息、时间、收入、设施、环境、社会支持等条件里。
- **短期舒服 ≠ 长期健康**：很多风险是累积的，短期没有后果，不等于没有代价。

**三层模型（本卷的骨架）：**

```text
Health outcome（健康结果）
≠ Health behaviour（健康行为）
≠ Conditions for behaviour（行为条件）
   信息 / 时间 / 收入 / 设施 / 环境 / 社会支持
```

**条件如何变成行为（本领域链）：**

```text
环境 / 条件
→ 可选选项
→ 成本 / 便利
→ 选择
→ 重复行为
→ 健康暴露
→ 健康结果
```

**为什么成立**

健康结果由行为长期累积而来，行为又由条件塑造。看到结果就直接怪个人，会跳过“行为”和“条件”两层。相关：`05_机制.md` 的转化 / 反馈延迟 / 可及性障碍；`07_深层母题.md` 的当下 ↔ 长期。

**常见题目**

亚健康、青年健康、健康意识、预防、生活方式病、健康教育。

## 二、知道 ≠ 做到

**核心区分**

- **获得信息 ≠ 理解信息**：能看到健康信息，不等于看得懂。
- **理解信息 ≠ 能判断质量**：看懂一句话，不等于能判断它是否可靠。
- **知道 ≠ 做到**：知识增加，不自动带来行为改变。
- **一次行动 ≠ 习惯**：做了一次，不等于形成了稳定模式。
- **意志力 ≠ 唯一决定因素**：行为能否持续，还取决于环境是否让健康选择更容易。
- **失败一次 ≠ 整个习惯失败**：一次中断不等于回到原点；能否恢复更关键。

**本领域主链：**

```text
健康信息
→ 理解
→ 判断
→ 意愿
→ 机会 / 条件
→ 行为
→ 重复
→ 习惯
→ 长期健康结果
```

断裂点：access ≠ understanding ｜ understanding ≠ appraisal ｜ appraisal ≠ action ｜ action once ≠ habit ｜ habit ≠ guaranteed outcome。

**为什么成立**

这是一条转化链，不是自动传送带。任何一环断了，知识都变不成健康结果。相关：`05_机制.md` 的转化 / 反馈延迟；`07_深层母题.md` 的当下 ↔ 长期。

**常见题目**

健康教育、健康科普、自律、坚持、坏习惯、网络健康信息、伪科学。

## 三、运动、饮食、睡眠：一次行为 ≠ 长期模式

**核心区分**

- **身体活动 ≠ 体育竞技 / 健身房训练**：走路、骑车、日常活动都算；健康不要求运动能力。
- **运动 ≠ 体育**：运动是身体活动，体育还包含规则、竞技和组织。
- **久坐 ≠ 运动不足**：完成运动目标，不等于消除长时间久坐；一个人可以规律运动，同时每天坐很久。
- **强度 ≠ 坚持**：偶尔高强度，不等于长期活跃；可持续的中等行动，常比短期极端更有效。
- **运动更多 ≠ 永远更好**：运动要适合个人条件和承受能力，不是越多越好。
- **健康饮食 ≠ 单纯少吃**：质量、结构、多样性也重要。
- **一种“健康食品” ≠ 健康饮食模式**：单一食物不能补偿整体饮食问题。
- **休息 ≠ 浪费时间**：休息是持续表现的条件，不是工作的反面。
- **少睡 ≠ 更努力**：少睡增加的是清醒时间，不一定是有效产出；一次补觉也不能修复长期不规律。

**为什么成立**

健康行为的效果来自“重复 + 可持续”，不是一次性冲刺。运动、饮食、睡眠都受同一个规律支配：短期极端很难维持，长期模式才产生结果。相关：`05_机制.md` 的边际递减 / 挤占 / 能力形成；`07_深层母题.md` 的当下 ↔ 长期。

**常见题目**

体育锻炼、久坐、减肥、饮食结构、熬夜、睡眠、健康生活方式、校园跑步。

## 四、个人责任 ≠ 完全个人控制

**核心区分**

- **个人责任 ≠ 完全个人控制**：个体行为重要，但行为受时间、收入、工作压力、环境、服务可及性、社区设施、社会规范影响。
- **同样的建议 ≠ 同样的执行能力**：同一条健康建议，对不同人的实际成本不同。
- **设施存在 ≠ 真正可用**：有健身房、公园、医院，不等于目标人群用得上。
- **机会平等 ≠ 结果完全相同**：公平是缩小可避免的健康差距，不是让所有人健康结果一模一样。
- **健康差距会反过来强化社会差距**：健康差 → 学习 / 工作能力下降 → 机会减少 → 处境更差。

**本领域主链：**

```text
社会经济处境
→ 住房 / 时间 / 资源
→ 可行的健康选择
→ 健康
→ 学习 / 工作能力
→ 未来机会
→ 进一步处境
（闭环：劣势 → 健康差距 → 机会差距 → 新的劣势）
```

**为什么成立**

个人选择发生在具体条件里。成熟判断不是“健康完全是个人责任”，也不是“个人没有责任”，而是：**个人行为发生在具体条件之中。**相关：`05_机制.md` 的可及性障碍 / 错配 / 外部性；`07_深层母题.md` 的自我 ↔ 相互依赖、个体差异。

**常见题目**

健康公平、公共健身设施、城乡健康差异、健康教育责任、工作压力与健康、老年人健康服务。

## 五、身体、心理、社会是一套系统

**核心区分**

- **心理健康 ≠ 没有心理疾病**：还包括应对日常压力、正常运转、维持关系的能力。
- **压力 ≠ 必然有害**：影响取决于强度、持续时间、可用资源；适度挑战可以促进行动，长期过载才有害。
- **“保持积极” ≠ 解决实际问题**：积极心态可以帮助应对，但不能消除产生压力的条件。
- **独处 ≠ 孤独；社交数量 ≠ 支持质量**：联系很多，不等于有稳定支持。
- **竞争 ≠ 敌意**：健康竞争可以检验表现，不需要把对手当敌人。
- **精英体育成功 ≠ 全民体育参与**：少数人的成绩，不等于大众活动水平。
- **身体与心理不是两套互不相关的系统**：健康行为往往同时影响身体和心理。

**本领域主链：**

```text
运动 / 体育
→ 体能 + 疾病预防
→ 共同活动 → 互动 → 社会连接
→ 挑战 / 进步 → 信心 / 幸福感
```

**为什么成立**

健康不只是身体指标；心理和社会连接也会影响行为与结果。运动的价值也不只在“强身”，还在社会连接、信心和持续参与。相关：`05_机制.md` 的正反馈 / 阈值；`07_深层母题.md` 的主观 ↔ 客观、个性 ↔ 归属。

**常见题目**

压力管理、孤独、社交媒体的心理影响、容貌焦虑、体育精神、团队运动、心理健康。

## 六、便利 / 技术 ≠ 无条件健康收益

**核心区分**

- **技术节省体力 ≠ 提高整体健康**：省力工具减少日常活动，可能同时减少运动机会。
- **数字连接 ≠ 高质量社会联系**：联系更多，不等于关系更深。
- **健康数据 ≠ 行为改变**：设备能测量习惯，不能替用户形成习惯。
- **便利 ≠ 无条件受益**：便利解决一个问题，可能制造另一个问题；健康效果取决于它替代了什么活动。
- **短期舒服 ≠ 长期健康**：便利的代价常常延迟出现。

**本领域主链：**

```text
技术 / 城市化 / 便利
→ 体力消耗减少
→ 日常活动减少
→ 久坐 / 活动不足

同时：技术 → 省时 / 方便
→ 一个维度的收益，另一个维度的代价
```

**为什么成立**

便利不是“好”或“坏”，而是**一个维度上的收益，可能对应另一个维度上的成本**。相关：`05_机制.md` 的替代 / 挤占 / 成本转嫁；`07_深层母题.md` 的便利 ↔ 能力；`08_常用故事.md` 的“生活更方便，健康不能外包”。

**常见题目**

手机使用、外卖、久坐、健康 App、智能穿戴、智能家居、远程办公。

## 七、预防 / 医疗 / 自我保健有分工

**核心区分**

- **健康 ≠ 医疗**：医疗系统处理疾病，健康还取决于日常生活和环境。
- **治疗 ≠ 预防**：治疗发生在疾病之后，预防试图降低发生的可能性。
- **预防的价值常常“看不见”**：它的成功表现为“问题没有发生”，所以容易被低估。
- **自我保健 ≠ 自己给自己看病**：自我保健是补充专业医疗，不是替代。
- **医疗可及 ≠ 实际获得有效医疗**：可用、可负担、质量是不同维度。
- **早发现 ≠ 预防**：筛查能更早发现风险，但发现不等于阻止发生；还要有后续行动。
- **强大医疗 ≠ 能完全补偿不健康环境**：医疗重要，但健康很大一部分在医院之外产生。

**本领域主链：**

```text
预防
→ 降低风险发生
→ 问题没有出现（价值不可见）
→ 长期健康结果

医疗
→ 疾病发生后治疗
→ 控制损害
→ 但不能替代日常健康条件
```

**为什么成立**

治疗、预防、自我保健解决的是不同环节的问题；把它们混成一件事，就会得出“医疗够了”“个人注意就行”或“预防没用”的错误结论。相关：`05_机制.md` 的转化 / 可及性障碍 / 替代；`07_深层母题.md` 的当下 ↔ 长期。

**常见题目**

体检、医疗资源、预防意识、自我保健、医保、公共卫生、健康教育。

## 八、怎么用这一卷

1. 先看“题目 → 领域思路”或 28 个区分速查，选**一个**最相关的。
2. 不要把 28 个区分全部套上；一个核心够用。
3. 链条只写到本题真正断的那一环，不要从头背到尾。
4. 回到本题材料：对象是谁？哪一环有证据？哪一环只是推测？
5. 够写就停。

本卷没有单列的两个旧话题：

- **容貌焦虑**：核心更接近社会比较 / 自我接纳，不是健康三层模型；以后归 `08_常用故事.md` / `02_素材`。
- **生命教育与人生规划**：属于人生意义 / 价值观，不是健康行为结构；以后归 `B/12` 哲理 / `09_话题思路`。

如果题目缺的是健康词汇、现象背景、例子 → `02_素材`；如果缺的是英语表达 → `03_表达`。
