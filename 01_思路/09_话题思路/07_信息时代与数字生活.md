## 一、数字接入 ≠ 有效使用 ≠ 真正参与

**核心区分**

- **设施存在 ≠ 能够接入**：有网络、有设备，不等于每个人都能稳定、负担得起地接入。
- **能够接入 ≠ 会有效使用**：能上网，不等于会用、用得起、用得对。
- **会使用 ≠ 真正参与**：能操作，不等于能表达、被看见、获得服务或机会。
- **数字接入不是“有 / 没有”的二元状态**，而是一条分层转化链。

**本领域链：**

```text
基础设施存在
→ 能够接入
→ 能够操作
→ 能够理解
→ 能够有效使用
→ 能够真正参与
→ 获得实际收益
```

**为什么成立**

每一层都可能断；平均技术进步不等于每个人都能受益。相关：`05_机制.md` 的可及性障碍 / 转化 / 错配；`07_深层母题.md` 的个体差异。

**常见题目**

数字鸿沟、老年人数字服务、城乡网络差异、数字素养、在线政务、远程医疗。

## 二、信息更多 ≠ 知识更多

**核心区分**

- **信息 ≠ 知识**：能接触到信息，不等于理解了、记住了、会用了。
- **信息数量 ≠ 信息质量**：内容更多，不等于更可靠、更相关。
- **接触 ≠ 理解**：看到过，不等于看懂。
- **理解 ≠ 能判断**：看懂一句话，不等于能判断来源、证据和意图。
- **信息供给增加 → 筛选成本上升**：信息越多，选择、核验和忽略的成本越高。

**本领域链：**

```text
信息供给增加
→ 注意力竞争加剧
→ 筛选成本上升
→ 来源判断变得更重要
→ 更多信息未必形成更多知识
```

**为什么成立**

信息环境的核心问题不是“有没有信息”，而是“能不能从大量信息中形成可靠判断”。相关：`05_机制.md` 的挤占 / 转化；`07_深层母题.md` 的主观认知 ↔ 客观现实；`01_看材料.md` 的 Evidence Ceiling。

**常见题目**

信息过载、碎片化阅读、网络谣言、媒体素养、事实核查、后真相、短视频学习。

## 三、推荐 ≠ 自主选择

**核心区分**

- **个性化 ≠ 自主**：系统更懂你的偏好，不等于你拥有更强的自主判断。
- **推荐 ≠ 独立选择**：你看到什么，可能已经被平台的目标和算法排序过。
- **相关 ≠ 多元**：推给你的内容可能“相关”，但不一定让你看到不同立场。
- **参与度 ≠ 用户福祉**：平台奖励停留、点击、互动，不等于这些指标对用户有长期价值。
- **平台指标会反过来塑造内容**：创作者为指标优化，内容适应指标，用户行为再反馈给系统。

**本领域链：**

```text
平台目标（停留 / 点击 / 互动）
→ 推荐排序
→ 用户看到的内容
→ 用户以为的“自己的选择”
→ 行为继续产生数据
→ 下一轮推荐
```

**为什么成立**

推荐系统不只是“把内容送到你面前”，它还在塑造你看到什么、以为什么重要。相关：`05_机制.md` 的正反馈 / 放大 / 指标博弈；`07_深层母题.md` 的自由 ↔ 规则、指标 ↔ 实质；`08_常用故事.md` 的“选择越多，判断越稀缺”（只链接，不复制）。

**常见题目**

信息茧房、回声室、推荐算法、短视频、极化、算法与公共讨论、平台内容治理。

## 四、屏幕时间 ≠ 数字生活质量

**核心区分**

- **总时长 ≠ 使用目的**：工作、学习、创作、社交、被动刷视频，都算屏幕时间，但性质不同。
- **使用目的 ≠ 使用方式**：主动使用和被动消费，效果不同。
- **使用方式 ≠ 实际结果**：同样的时长，可能带来学习、连接、放松，也可能带来疲劳、焦虑、拖延。
- **数字生活质量取决于“用来做什么、怎么用”，不只取决于“用了多久”。**

**本领域链：**

```text
总屏幕时间
→ 使用目的
→ 使用方式（主动 / 被动）
→ 实际结果（学习 / 连接 / 放松 / 疲劳）
```

**为什么成立**

只用时长判断数字生活，会把不同性质的活动混成一类。相关：`05_机制.md` 的挤占 / 反馈延迟；`07_深层母题.md` 的便利 ↔ 能力、当下 ↔ 长期。

**常见题目**

屏幕时间、短视频、游戏、在线学习、远程办公、数字排毒、注意力。

## 五、数据便利 ≠ 知情控制

**核心区分**

- **便利 ≠ 没有代价**：免费服务、个性化推荐、便捷支付，往往以数据和注意力为交换。
- **收集数据 ≠ 用户真正同意**：点了“同意”，不等于理解数据怎么被使用。
- **同意 ≠ 有意义的控制**：形式上的授权，不等于用户能选择、撤回或质疑。
- **数据价值越高，安全责任越大**：平台从数据中获益，也应承担保护责任。
- **有些数据一旦泄露不可逆**：生物识别等信息不像密码可以更换。

**本领域链：**

```text
数据收集
→ 用户画像 / 预测
→ 个性化 / 便利
同时
→ 信息不对称 / 控制感下降
→ 信任与安全问题
```

**为什么成立**

隐私问题不只是“愿不愿意交换”，还包括信息不对称、平台权力和不可逆风险。相关：`05_机制.md` 的外部性 / 成本转嫁；`07_深层母题.md` 的便利 ↔ 自主、自由 ↔ 规则。

**常见题目**

隐私泄露、人脸识别、数据垄断、用户协议、监控、免费应用、平台监管。
