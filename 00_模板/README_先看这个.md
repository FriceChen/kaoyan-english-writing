## 考前40天的轻量训练安排

- **第1—3天**：只掌握第一段的6类起句、第二段3种路径、第三段3种收束方式；改掉“所有图表都很流行”等错误默认值。
- **第4—10天**：练4题：2026养老机器人、2025家电、2024公园（画＋表）、2023龙舟（纯图画）。每题先30秒中文破题，再写三段英文，查缺后只补真正不会的1–3条表达。
- **第11—25天**：再练6—8题（优先英二近年图表及英语一较早图画），其中至少3次按时限完成大作文；小作文穿插练习，不再建新小作文体系。
- **第26—35天**：做3—4次大小作文联练；只复盘反复出现的错误和卡点。
- **最后5天**：只看执行卡、实际掌握的核心表达和个人高频错误；不引进大批新的范文、主题或模板。

> 训练量按专业课压力可上下浮动。关键指标是**独立完成一篇切题文章所需要的时间、卡顿位置、重复错误**，不是累计收集多少条语料。
