# 怎么用素材

> `01_思路` 决定往哪里写；`02_素材` 提供具体话题里的内容；`03_表达` 负责把已经知道的意思写成英语。
>
> 素材不是思路。`Digital divide`、`Silver economy`、`Greenwashing`、`Ghosting` 是素材对象；“信息更多 ≠ 知识更多”“机会 ≠ 结果”“商业化 ≠ 必然破坏”在 `01_思路`。

---

## 1. 什么时候该打开素材

一句话：

> **我大致知道文章要往哪里写，但缺少这个题具体在说什么、有哪些概念、场景或例子。**

- **AI 教育题**：想写“AI 是辅助不是替代”，但不知道 AI 在学习里具体能做什么 → `09_教育与学习.md` + `04_科技与AI.md`。
- **老龄题**：想谈社会参与，但不知道 silver economy / ageism / age-friendly environment 是什么 → `06_社会与公共生活.md`。
- **新热词**：搭子、City Walk、特种兵旅游 → 先看 `12_动态话题索引.md`，再进稳定卷。

---

## 2. 什么时候不要打开素材

1. **不知道怎么分析题** → `01_思路`。
2. **知道写什么，只是不会英语** → `03_表达`。
3. **已经有 2–3 个展开点** → 直接写，不要为了“素材丰富”继续查。
4. **只想找一句漂亮话** → `03_表达`。

---

## 3. 三个 Gap：先判断缺什么

| 缺口 | 表现 | 去哪 |
|---|---|---|
| **Thought Gap** | 不知道应该说什么 / 怎么分析 | `01_思路` |
| **Content Gap** | 知道方向，但不知道这个具体话题有什么对象、概念、场景 | `02_素材` |
| **Language Gap** | 意思已经清楚，不知道英语怎么表达 | `03_表达` |

判不准时只问一句：

> **我是不知道“写什么”，还是不知道“这个题里有什么”，还是不知道“英语怎么说”？**

---

## 4. 打开一卷以后怎么看

每个稳定卷都是同一结构：**题域 → 概念 → 场景 → 可用判断 → 典型例子 / 应用 → 相邻入口**。

不要从头看到尾：

1. **题域**：确认有没有进对卷。
2. **概念**：只补不认识的词 / 对象，不背整张表。
3. **场景**：找 1–2 个能直接写进文章的具体内容。
4. **判断**：还缺一句具体判断时再看。
5. **应用**：需要具体化时再看。
6. **相邻入口**：题目跨领域时再看。

> 素材卷不是教材，不要求从第一行背到最后一行。它是训练和查漏工具，不是考场数据库。

---

## 5. 够用就停：素材的最低调用量

一篇正常作文通常不需要 10 个概念、5 个例子或整卷知识。通常只需要：**1–2 个具体概念 + 1–2 个现实场景 + 必要时 1 条具体判断。**

**素材是填洞，不是堆料。**

停止条件：能回答下面三个问题——

1. 题目具体在说什么？
2. 我准备写哪 2–3 个点？
3. 每个点有没有具体内容可以落地？

> **停止查素材，去写。**

---

## 6. 跨领域题：主入口 + 次入口

不要找“唯一正确卷”：**主入口 1 个，次入口最多 1–2 个。**

- **AI + 教育**：主 `09_教育与学习`，次 `04_科技与AI`。
- **老龄 + 数字**：健康服务 → 主 `03`；数字可及 → 主 `05`；社会参与 → 主 `06`。
- **文创消费**：主 `08_文化与传承`；强调购买行为再看 `02_消费与财商`。

## 7. 新热词与 `[动态]`

**新名字 ≠ 新问题。**

```text
新热词 → 找上位对象 → 进入稳定素材卷
→ 只有流行度 / 平台 / 产品等真正动态内容需要临考更新
```

新热词先看 `12_动态话题索引.md`；不要为每个新词新建素材。

`[动态]` 不代表概念不可靠，而是：概念稳定，具体工具 / 平台 / 产品会变化。平时学稳定定义和场景；临考只检查少量动态表现，入口在 `12_动态话题索引.md`。

---

## 8. 三个栏目的边界

- **“可用判断”不是 Argument Bank。** 它只是依赖具体对象的增量判断，不是必背中心句、固定立意或万能论点；有自己的判断就不用看。
- **“典型例子 / 应用”不是案例库。** 它们只帮助把概念变具体，不是名人例子库，也不是必须背下来的完整案例。
- **“相邻入口”不是必读。** 只在题目跨领域时用，不要为了“看全”把相邻卷全打开。

---

## 9. 不要背数字

素材体系刻意没有大量年份、百分比、市场规模和政策数字。考研大作文通常不需要精确统计才能成立。

- 题目给数字 → 用题目材料。
- 临考需要当年背景 → 走 `12_动态话题索引.md` 的临考更新清单。

---

## 10. 训练时怎么用

- **第一次接触一个领域**：快速浏览“题域 → 概念 → 场景”，建立熟悉感。
- **做到具体作文题**：只补当前的 Content Gap。
- **练完以后**：记录哪几个素材已经自然能调用。

不需要周计划、打卡、间隔重复系统或单独训练模块。

### 避免素材焦虑

一篇文章不是知道得越多越好。考场需要的是：看懂题 + 2–3 个能展开的点 + 具体内容 + 能用英语写清楚。这些都满足后，继续查素材收益很低。
