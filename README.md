# 考研英语写作体系（kaoyan-english-writing）

个人考研英语写作备考体系：四层分工，按缺口查对应模块，不强制顺次完成四步。

| 目录 | 层 | 回答的问题 |
|---|---|---|
| `00_模板` | 执行层 | 文章怎样组织：考场执行卡 / 固定句 L0–L1–L2 / 专项训练手册与台账 |
| `01_思路` | 思考层 | 这个问题怎样想：00–10 审题工具 + 8 卷话题思路 |
| `02_素材` | 内容层 | 这个话题有什么可写：11 领域卷 + 动态话题索引 |
| `03_表达` | 语言层 | 意思已定，英语怎么写：功能句 / 图表用语 / 主题搭配 / 个人语料库 |

入口：`00_模板/00_考场执行卡.md`（考场流程）与 `01_思路/00_怎么用.md`（审题思路）。
