# 共享功能表达

> 本文件是 `03_表达` 的核心 canonical source：把已经确定的中文意思实现为通用语言动作。
>
> 只收跨领域功能句；不收位置接口、图表 warehouse、话题搭配、金句、小作文。
>
> **Meaning → Language**：先有明确意思，再选功能。
> **Functions are NOT stages**：F1–F6 是语言动作标签，不是六步流程；允许 function stacking。

---

## 0. 使用纪律

1. 先确定中文意思；意思不清 → 回 `01_思路` / `02_素材`。
2. 按当前句子的语言动作选功能，不按 F1→F6 顺序走。
3. 每个功能只保留少量 default / alt；其余 `[REF]`。
4. 不标 Active 标签；Active 在 Batch 7 从 default 中精选。
5. 槽位 X / Y / A / B 按题目替换；不把话题名写死。

---

## 1. F1 DESCRIBE

**功能：** 描述现象、变化、差异、比例 / 数量、图片 / 数据的基础入口。
**不负责：** 解读意义（F2）、解释原因（F3）、详细图表 warehouse（04）。

### 现象

- `[DEFAULT]` X is characterized by ...
- `[DEFAULT]` In recent years, X has become ...
- `[ALT]` X is increasingly common in ...

### 变化

- `[DEFAULT]` The figure for X increased / decreased from A to B.
- `[DEFAULT]` X has changed from A to B.
- `[ALT]` The proportion of X rose / fell over the period.

### 差异 / 比例

- `[DEFAULT]` X was higher / lower than Y.
- `[DEFAULT]` X accounted for Y% of the total.
- `[ALT]` The gap between X and Y widened / narrowed.

### 图片 / 数据入口

- `[DEFAULT]` The picture shows X.
- `[DEFAULT]` The chart presents data on X.
- `[ALT]` A closer look reveals X.

> 完整开场接口 O1–O5 见 `03_Position_Interfaces`；详细趋势动词、幅度、排名、倍数、一画一表见 `04_Figure_Chart`。

---

## 2. F2 INTERPRET

**功能：** 从材料 / 现象 / 数据推进到意义。
**不负责：** 决定意义是什么；意义内容由 `01_思路` 提供。

- `[DEFAULT]` This pattern suggests that ...
- `[DEFAULT]` The contrast points to ...
- `[ALT]` What matters here is not X itself, but ...
- `[ALT]` This trend reflects a broader shift from A to B.

> 只写“这说明……”；不要在这里替用户决定“应该解读成什么”。

---

## 3. F3 EXPLAIN

**功能：** 原因、结果、机制、条件、链条、促进因素、限制。
**不负责：** 建立机制知识；机制内容来自 `01_思路`。

### 因果

- `[DEFAULT]` X can lead to Y.
- `[DEFAULT]` X contributes to Y by ...
- `[ALT]` X affects Y partly because ...
- `[ALT]` X may contribute to Y, especially when ...
- `[ALT]` A does not have to come at the expense of B.
- `[ALT]` X may place a burden on Y.

### 机制链

- `[DEFAULT]` X can trigger Y, which in turn ...
- `[DEFAULT]` X creates the conditions for Y, which ...
- `[ALT]` A can serve as a bridge between X and Y.
- `[ALT]` X affects Y through Z; Y then affects ...

### 条件 / 限制

- `[DEFAULT]` Whether X can produce Y depends on ...
- `[DEFAULT]` X works only when ...
- `[ALT]` X is necessary but not sufficient for Y.
- `[ALT]` X can deprive someone of the opportunity to ...
- `[ALT]` X can prevent someone from ...ing.

---

## 4. F4 RELATE

**功能：** 对比、让步、比较、递进、限定、举例、换句话说、A 与 B 的关系。
**不负责：** 评价（F5）、建议（F6）。

- `[DEFAULT]` To begin with, ... / In the first place, ...
- `[DEFAULT]` Moreover, ... / In addition, ...
- `[DEFAULT]` By contrast, ...
- `[DEFAULT]` While A ..., B ...
- `[DEFAULT]` Even when X ..., Y still ...
- `[DEFAULT]` Rather than X, Y ...
- `[DEFAULT]` Not simply X, but Y ...
- `[DEFAULT]` For example, ...
- `[ALT]` This is best exemplified by ...
- `[ALT]` In other words, ...
- `[ALT]` More precisely, ...
- `[ALT]` This does not mean that ...
- `[ALT]` This is particularly true when ...

> 不扩 50 个 transition synonym；只保留真正高频、语义有差异的。

---

## 5. F5 EVALUATE

**功能：** 意义、好处、担忧、限制、有限认可、优先性、不确定性。
**不负责：** 建议具体行动（F6）。

- `[DEFAULT]` This matters because ...
- `[DEFAULT]` The value of X lies in ...
- `[DEFAULT]` The concern is not X itself, but ...
- `[DEFAULT]` X can be useful, but its value depends on ...
- `[ALT]` X is beneficial up to a point; beyond that, ...
- `[ALT]` It is not clear whether X ...
- `[ALT]` It is unrealistic to expect that ...
- `[ALT]` There is little reason to assume that ...

> 不写 `X is very important / plays a vital role / is of great significance` 的同义堆。

---

## 6. F6 RECOMMEND（OPTIONAL）

**功能：** 行动、优先项、责任、条件、目标。
**不负责：** 产生新的政策内容；不是每篇都需要。

- `[DEFAULT]` The priority should be to ...
- `[DEFAULT]` A more effective approach is to ...
- `[DEFAULT]` What is needed is not simply X, but Y.
- `[ALT]` [Actor] should [verb] so that ...
- `[ALT]` X needs to be accompanied by Y.

> 不默认 `Measures should be taken.`；建议至少包含 actor / action / goal 中的两个。

---

## 7. G1–G5 控制

### G1 Accuracy

- from / to / by 不混用；
- percentage vs percentage points；
- ranking、proportion 说清楚；
- 不虚构人物心理，不把相关写成因果。

### G2 Abstraction

- 默认只向上抽象一层；
- 继续追问“为什么社会如此 / 为什么人类如此 / 深层张力是什么” → 回 `01_思路`；
- 不在 03 继续升维。

### G3 Strength

- 证据动词：suggest / point to / reflect / indicate；
- 因果强度：may contribute to < contribute to < lead to < cause；
- 证据弱，不用过强因果；
- 慎用 prove / demonstrate conclusively。

### G4 Specificity

- 避免 `Technology is beneficial.` / `Measures should be taken.` / `This is very important.`；
- 说清谁、什么行为、什么结果。

### G5 Economy

- Function 是标签，不是句子配额；
- 一段不需要把所有 F 用一遍。

---

## 8. 数量纪律与标签

| 标签 | 用途 | 数量 |
|---|---|---:|
| `[DEFAULT]` | 最稳、最高频 | 每功能 1–3 |
| `[ALT]` | 真正有语义差异的替代 | 每功能 1–2 |
| `[REF]` | 低频但有价值 | 受控 |

- 不标 Active 标签；Active 在 Batch 7 从 default 中精选。
- 不建 synonym bank。
- 不把低频变体塞进 default。

---

## 9. 不放进本文件的内容

- **位置接口**：O1–O5、B0/B1、C0–C3 → `03_Position_Interfaces`；
- **详细图表 warehouse**：趋势动词、幅度、排名、倍数、一画一表 → `04_Figure_Chart`；
- **话题绑定搭配**：具体话题的固定动词 + 名词 → `05_Topic_Expression`；
- **Signature**：G01–G12、SA1–SA8、MN、ET、Lens、Mechanism → `06_Signature_Optional` / `01_思路`；
- **小作文**：Invite / Request / Apologize / Thank / Notice / Memo → `07_Small_Essay`；
- **评分 / 训练协议** → 不进入 `03_表达`。

---

## 10. 功能叠加示例

```text
X can lead to Y. This matters because Y affects Z. The priority should be to ...
```

这是 F3 → F5 → F6 的叠加，不是“三段模板”，也不是必须按顺序走。
