# 09 人语料库（Personal Repertoire / Ownership State）

> **定位（2026-11-01 自旧体系 C/01 平移）：** **个人所有权记录**——不是第五/第六类句型：`03_表达` 各表的句子，被你真实采用后，采用证据落在这里。与检索层（`02_素材`、`03_表达` 各表）物理分离。
>
> **核心原则（为什么有这个文件）：**
> - `02_素材` / `03_表达` 各表是外部记忆，归 **Agent 检索**用（Recognition），你不背不翻；
> - 真正属于你、你调得出来的表达，只能由**真实写作**长出来（你卡壳 → Agent 给候选 → 你采纳/重建 → 写进作文 → 沉淀到这里）；
> - 这里的一切都**经过你的大脑**——用过，才放进来。是 Output-driven 的唯一产物。
>
> **准入（不变）：** 真实需要 + 实际采用 + 还想再用。
>
> **lifecycle：** Adopted → Active → Retired。
> - **Active 判定**：看 evidence——actual use + successful REBUILD + independent retrieval + transfer；**使用次数只是辅助证据，"×3 自动 Active"废除**；
> - **≤80 只约束 CURRENT ACTIVE REPERTOIRE**；历史 / Retired 条目保留不删、不计入；**迁移时不自动归类（MUST NOT automatically classify）**。
>
> **格式：** 表达 | 我第一次用在哪 | 人话意思 | 例句 | 用过几次
>
> **REBUILD 练习对象之一**（`03_Position_Interfaces.md` 的位置接口同样需要自动化——本文件不是唯一要内化的资产）。
>
> **阅读侧分工：** 熟词僻义（阅读防错）仍在 `阅读积累/熟词僻义.md`；写作面条目随训练沉淀进本文件。

## 用法提醒（给 Agent）

- 训练时：用户卡壳 → 从 `03_表达` 各表 / `02_素材` 检索/生成候选 → 用户采用后 → **沉淀进本文件**；
- 沉淀条件（缺一不可）：① 用户真实需要；② 用户实际采用并写进作文；③ 用户表示"还想用" 或 判断有迁移价值；
- 沉淀时自动记录"第一次用在哪"（哪道题/哪个意思）；
- 每次训练结束检查本文件：被再次使用的表达 +1 次（**次数是 evidence，不是 Active 的充分条件**）；Active 判定 = actual use + successful REBUILD + independent retrieval + transfer；
- 本文件是 REBUILD（合上答案重写）练习的专用素材；
- 大作文语言三层：位置接口 canonical 归 `03_Position_Interfaces.md`；功能表达 canonical 归 `02_Shared_Functional.md`（F1–F6）；本文件存**采用记录与所有权**（如 #1 / #16 / #17 开场变体、#10 过渡问句），与各表 **cross-link，不搬迁、不 dedupe**——`04_Figure_Chart.md` 与位置/功能表允许表层重复。
