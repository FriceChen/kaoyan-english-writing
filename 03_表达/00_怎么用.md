# 怎么用表达

> `01_思路` = 我应该说什么、怎么分析
> `02_素材` = 这个具体话题里有什么内容
> `03_表达` = 我已经知道意思，怎样把它准确、自然、成熟地写成英语
>
> **中文意思没有确定以前，不进入 03。**

---

## 1. 什么时候进入 03

核心触发条件：

> **我知道自己要表达的中文意思，但不知道英语怎样实现。**

四种常见情况：

- **话题搭配**：中文已经确定“这种做法可能进一步扩大数字鸿沟”，但不会英语 → `05_Topic_Expression`（后续）+ `02_Shared_Functional`。
- **功能句**：中文已经确定“A 会导致 B，而 B 又进一步导致 C” → `02_Shared_Functional / F3`。
- **图表写法**：知道第一段要描述图表，但不知道上升、下降、占比、相比怎么写 → `04_Figure_Chart`（后续）。
- **小作文**：知道自己在写邀请信，但不知道正式邀请怎么说 → `07_Small_Essay`（后续）。

---

## 2. 什么时候不要进入 03

1. **不知道论点 / 不知道怎么分析** → `01_思路`。
2. **不知道话题本身有什么内容** → `02_素材`。
3. **已经有自然、准确的英语** → 直接写。
4. **只是想找“更高级”的同义词** → 先判断是否真的存在 Language Gap；不默认进入表达库。

> 不要用表达库解决思路问题，也不要用表达库解决素材问题。
>
> 新热词：先看 `02_素材/12_动态话题索引.md`，再判断是 Content Gap 还是 Language Gap。

## 4. Active / Reference

### Active

真正需要闭卷主动调用：

- 高频；
- 跨题；
- 稳定；
- 自然；
- 写作时能主动想起。

统一在 `01_Active_Core.md`（Batch 7）精选，≤80 条上限，不是配额。

### Reference

知道有、需要时查：

- 低频；
- 特定功能；
- 图表特殊用法；
- 小作文特殊情境。

直接留在各 canonical file 里，用 `[REF]` 标记。**不建立独立 Reference 大仓。**

## 5. Meaning → Language

必须先确定意思，再选表达。

禁止：

```text
看到一个漂亮句
→ 为了使用它
→ 反过来改变文章观点
```

后续 Signature 也受这条约束：金句只在对应思路真实出现时用，不能反向决定文章写什么。

## 7. 主题词不会写：优先降维，不要卡住

原则：

```text
准确 > 高级
会写 > 生僻
能贯穿全文 > 单个漂亮词
```

主题词想不起抽象名词时，换词性降维：

```text
名词 → being + adjective → gerund / action phrase
```

例：

```text
honesty / integrity → being honest → telling the truth
employment → finding a job
entrepreneurship → starting one's own business
```

整段只会写一个主题词时，可用指示代词承接，避免机械重复：

```text
品质类：this quality / this trait
行为类：this habit / this action / this behavior
```

> 只有前文指代对象明确时才使用；不要为了避免重复而连续使用含糊的 `this`。
